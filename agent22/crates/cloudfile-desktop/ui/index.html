    工作区
    本地任务
    
      
    
    
    

    
    
      仍有独占编辑任务或未确认的上传。
      
    
      
    退出会停止后台续租，但不会释放 Checkout，也不会删除本地工作副本与待确认的 Intent。
    
      
    
        
        
      
    
    
    

    
    
      
      
    
      
    
        
        
      
    
    
    

    
    
      普通本地编辑：在本地应用保存后，Agent 会在文件内容稳定后自动上传，可暂停或点击“保存云端”立即提交。
      独占编辑：从网页发起后由 Agent 领取 Checkout 租约，由你点击“提交”保留 Checkout，或“签入并释放”结束本次独占；
      提交结果未确认前不会自动重发，本地文件始终保留。两种模式每次最多 128 MiB。
    
    

    
    

    
    
      
    本机设置
    
      
    这些是本机偏好，不是授权：改通知或浮标都不会上传文件，也不会释放 Checkout。
